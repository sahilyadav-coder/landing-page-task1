# Task 1 — Responsive Landing Page

A clean, responsive landing page built as part of the Web Development Internship (ElevateLabs).

## 🛠️ Tools Used
- HTML5
- CSS3
- Flexbox & Grid
- Media Queries
- VS Code + Live Server

## 📁 Files
- `index.html` — Main HTML structure
- `style.css` — All styling and responsiveness

## 🚀 How to Run
1. Download or clone this repository
2. Open the folder in VS Code
3. Right-click `index.html` → Open with Live Server
4. View at `http://127.0.0.1:5500`

## 📌 Key Concepts Covered
- Semantic HTML5 tags (header, nav, section, footer)
- CSS Flexbox for 1D layouts
- CSS Grid for 2D layouts
- Media queries for mobile responsiveness
- CSS Variables, animations, and transitions

## 📸 Features
- Sticky responsive navbar with hamburger menu
- Hero section with CTA buttons
- Features section with card grid
- Footer with social links
